# Mini Game Testing with Selenium

This folder contains automated tests for my custom mini-game.

## Files
- `test_movimiento_y_puntuacion.py` – Selenium test validating player movement and score updates.

## Tools & Frameworks
- Selenium WebDriver
- unittest

## Highlights
- End-to-end testing of a game interface
- Validates score changes when moving to different tiles
- Shows creative use of Selenium beyond standard web forms
