# Visualization · Turning Torso

This folder contains my Streamlit + Matplotlib visualization project.

## Files
- `StreamTORRE.py` – interactive 3D tower visualizer.
- `screenshots/` – images of the visualization in action.

## Tools & Frameworks
- Streamlit
- Matplotlib
- NumPy

## Highlights
- Parametric 3D visualization of a twisting tower
- Interactive controls for floors, rotation, shape, and color
- Demonstrates debugging persistence and creative visualization
